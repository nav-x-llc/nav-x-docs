# Welcome to the External File Storage - Datto Workplace Connector Help

The **External File Storage - Datto Workplace Connector** is an app for Microsoft Dynamics 365 Business Central that connects Business Central to your Datto Workplace account, making Datto Workplace a native external file storage provider for all Business Central file operations.

## What Is This App?

When installed, this connector registers Datto Workplace as an option in Business Central's **External File Storage** system. Any Business Central feature that stores or retrieves files — document attachments, report output, integration file pickup and archiving, and other file-related workflows — can use Datto Workplace as its storage back-end without any additional configuration.

You manage Datto Workplace accounts directly inside Business Central. There is no need to switch between applications or manually transfer files — everything is handled transparently through Business Central's standard file interfaces.

## Features

- **Guided Account Setup** — a step-by-step wizard helps you connect a Datto Workplace account in minutes
- **Multi-Account Support** — configure as many Datto Workplace accounts as needed, each pointing to a different organization or project structure
- **Multi-Region Support** — connect to any Datto Workplace region (US, EU, CA, AU) and any of 18 data center cells
- **Secure Credential Storage** — Client ID and Client Secret are stored in BC's isolated storage and never written to the database
- **Full File Operations** — list, upload, download, copy, move, and delete files; create and remove folders
- **Project-Based Navigation** — Datto Workplace Projects appear as top-level folders in the storage browser; the full path hierarchy is navigable from within Business Central
- **Connection Testing** — verify credentials from the account card at any time without leaving Business Central
- **Account Browser** — browse all Projects and folders in a Datto Workplace account directly from the Account Card
