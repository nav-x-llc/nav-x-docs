# External File Storage Trial Setup

If you want to try External File Storage with our free trial, install the app and start the 30-day free trial. You can use the full functionality for 30 days at no charge in any environment (production and sandboxes) in your Business Central tenant.

If you have not yet signed up for a Microsoft Dynamics 365 Business Central tenant, you can sign up for a free trial at the [Microsoft Dynamics 365 Trial](https://trials.dynamics.com/Dynamics365/Signup/businesscentral) page.

Once your tenant is provisioned, install the **External File Storage** app from [Microsoft AppSource](https://appsource.microsoft.com/en-US/). You will also need to install at least one connector app to provide the storage back-end. If you have questions about installing apps from AppSource, see the Microsoft documentation on [installing extensions](https://docs.microsoft.com/en-US/dynamics365/business-central/ui-extensions).
