# Page Custom Fields Report Visibility

After you define specific custom fields, you can control which reports display each field. This is configured through the **Custom Fields Report Visibility** page, accessible as an action from the **Custom Fields Definitions** page.

When you open the **Custom Fields Report Visibility** page from the **Custom Fields Definitions** page, it is filtered on the currently selected custom field and lists all reports that support that field. If a report you use is not listed, please contact us and we can consider adding it in a future release.

The following fields are available on the page.

| Field            | Description                                                          |
| ---------------- | -------------------------------------------------------------------- |
| **Report Name**  | The name of the report                                               |
| **Table**        | The table the custom field belongs to                                |
| **Type**         | The type of the custom field                                         |
| **Field No.**    | The number of the custom field                                       |
| **Visible**      | Defines whether this field is printed on the report or not           |
