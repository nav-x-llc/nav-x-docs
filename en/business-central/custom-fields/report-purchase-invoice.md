# Report Purchase - Invoice

The *Purchase - Invoice* report has been extended to optionally display custom fields. You can activate which fields appear on this report through the [Custom Fields Report Visibility](page-customfield-report-visibility.md) page.

The *Purchase - Invoice* report can show custom fields from the following tables:

| Table           | Supported Field Types                                    |
| --------------- | -------------------------------------------------------- |
| Purchase Header | Code, Boolean, Decimal, Integer, Date, Time, DateTime, Text |

All field numbers (1–5 in the base app, 6–10 with Extension Pack 1, 11–15 with Extension Pack 2) are supported for each field type.
