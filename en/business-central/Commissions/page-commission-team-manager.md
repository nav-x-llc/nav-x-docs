# Page Commission Team Manager

[!include[signup-tenant](includes/signup-tenant.md)]

The **Commission Team Manager** page defines which sales teams a salesperson manages. It is used in conjunction with the Manager Commissions feature. A salesperson who has one or more records on this page is considered a manager and will receive commissions calculated on the performance of the teams they manage. You can access this page from the **Salespeople/Purchasers** list or **Salespeople/Purchasers Card** using the action **Team Manager** (*Salespeople > Team Manager*).

> [!IMPORTANT]
> **Team Manager** is only shown as an action if you have turned on **Commissions for Managers** in the **Features** fast tab in the [Commission Setup](page-commission-setup.md).

A salesperson can manage multiple teams. The commission rates that a manager receives are defined on the salesperson's commission rates using the **Commission Manager Rate** setup. For more information, see [Working with Manager Commissions](how-to-manager-commission.md).

> [!IMPORTANT]
> Only Commission Managers (or licensed SaaS users) can edit this page.

|               |                                                                                                                                                          |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Team Code** | The sales team this salesperson manages. This corresponds to the **Team Code** field on the Salesperson card. A salesperson can be assigned multiple teams. |
| **Team Name** | The name of the team, displayed automatically based on the selected **Team Code**.                                                                        |
