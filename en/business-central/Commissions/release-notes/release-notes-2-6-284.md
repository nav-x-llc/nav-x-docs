# Release Notes for November 2025 Update - Version 2.6.284

## Resolved Issues

### Initial Sale Check Performance

When a customer had a very large number of sales transactions, the process to check whether a sale qualifies as an "initial sale" could fail or time out. The process has been optimized to handle large data volumes correctly.
