# Release Notes for October 2025 Update - Version 2.6.280

## Resolved Issues

### Initial Commission by Entity - Incorrect Calculation

When using the Initial Commission rates feature with the **Initial Rate per Entity** option enabled, commissions were not being calculated correctly in certain scenarios. The logic for determining whether a sale qualifies as an "initial sale" for a specific entity has been improved and corrected.
