# Release Notes for September 2025 Update - Version 2.6.277

## Resolved Issues

### Days Overdue Posting - GL Register Error

When the "Different Commissions for Overdue Documents" feature was enabled and the system attempted to post commission adjustments for overdue invoices, an error occurred indicating that a G/L Register already existed. This has been corrected.

### Opening Days Overdue Page from Salesperson

An error occurred when trying to open the Reduced Days Overdue Commissions page directly from the Salesperson card. This has been corrected.
