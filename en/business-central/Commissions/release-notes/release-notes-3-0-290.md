# Release Notes for March 2026 Update - Version 3.0.290

## Resolved Issues

### Swedish and Special Characters Causing Error

When using NAV-X Commission Management in environments with Swedish or other special characters (such as Å, Ä, Ö) in item descriptions, customer names, or other fields, an error was displayed when accessing the Commission Rates page. This has been corrected and NAV-X Commission Management now properly supports environments using Swedish and other special characters.
